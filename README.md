# Твоя служба

Основной сайт: https://romar-m.github.io/

Единый рабочий репозиторий: https://github.com/Romar-M/Romar-M.github.io

## Структура

- `app/` — исходники страниц, анкеты и панели управления.
- `public/` — изображения, стили и код для статической версии.
- `docs/` — готовая публичная версия сайта. GitHub Pages публикует эту папку из ветки `main`.
- `scripts/export-github-pages.mjs` — выгрузка публичных страниц без привязки к подпапке в адресе.

## Разработка

Нужны Node.js 22.13 или новее и pnpm.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm lint
pnpm build
```

Для экспорта запустите сервер проекта и выполните `pnpm export:pages`.
По умолчанию сервер ожидается на `http://localhost:3000`, результат сохраняется в `static-site/`.
Адрес сервера задаётся переменной `STATIC_SITE_ORIGIN`, папка вывода — `STATIC_SITE_OUTPUT`.
Перед обновлением `docs/` проверьте страницы, изображения и переходы. Каждое логическое изменение сохраняйте отдельным коммитом.

## Публикация

Обновите проверенную папку `docs/`, сохраните изменения и отправьте ветку `main`.
Настройка GitHub Pages: **Deploy from a branch → main → /docs**.
Все ссылки должны работать от `https://romar-m.github.io/`, без дополнительного имени репозитория.

GitHub Pages обслуживает только статические файлы. Серверные обработчики заявок, база данных и административная панель требуют отдельного серверного размещения; этот перенос их не публикует.
Личные данные заявителей, `.env` и локальную базу нельзя добавлять в репозиторий.
